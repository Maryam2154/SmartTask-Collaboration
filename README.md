# SmartTask

A project and team workspace built with Next.js, React, and TypeScript.

## Features

- Create, assign, search, and track projects and tasks
- Move tasks between To Do, In Progress, Review, and Completed
- View task-to-project associations in Board and List views
- Calendar with selectable dates and Month/Week modes
- Team and direct messaging
- Local file uploads and downloads
- Workspace settings and confirmed project/task deletion

## Getting Started

```bash
npm install
npm run dev
